# Yerel sipariş anonsları

Uygulama ve Windows bildirim aracı bu klasördeki dört **gerçek M4A** dosyasını aynı yollarla kullanır. Dosya bulunmazsa yüklü Türkçe Windows konuşma sesi, o da yoksa sistem uyarı tonu kullanılır. Dört özgün Türkçe Canva Ozan M4A dosyası kullanıcı tarafından yüklenmiş ve SHA-256 değerleri yüklenen orijinallerle birebir doğrulanmıştır.

| Dosya | Türkçe sabit metin |
|---|---|
| ozan_1.m4a | Alfa Copy Center. Yeni siparişiniz var. |
| ozan_2.m4a | Yeni bir sipariş alındı. Lütfen sipariş havuzunu kontrol edin. |
| ozan_3.m4a | Dikkat. Yeni sipariş işleme hazır. |
| ozan_4.m4a | Yeni sipariş bildirimi. Sipariş listesini kontrol ediniz. |

Canva Text to Speech → Türkçe → Ozan çıktıları özgün M4A biçiminde saklanır. WAV veya MP3 dosyaları da kendi uzantılarıyla desteklenir; uzantıyı değiştirerek biçim dönüştürmeyin. Personel/Yönetici ve AlfaBildirim paketlerine bu klasör otomatik olarak dahil edilir. Uygulama hiçbir müşteri veya sipariş verisini ses servisine göndermez.
