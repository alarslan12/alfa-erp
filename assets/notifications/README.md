# Yerel sipariş anonsları

Uygulama ve Windows bildirim aracı bu klasördeki dört **gerçek WAV** dosyasını aynı yollarla kullanır. Dosya bulunmazsa yüklü Türkçe Windows konuşma sesi, o da yoksa sistem uyarı tonu kullanılır. Canva Ozan sesiyle üretilmiş dosyalar henüz depoya eklenmemiştir; aşağıdaki metinler üretim talimatıdır, ses dosyası değildir.

| Dosya | Türkçe sabit metin |
|---|---|
| ozan_1.wav | Alfa Copy Center. Yeni siparişiniz var. |
| ozan_2.wav | Yeni bir sipariş alındı. Lütfen sipariş havuzunu kontrol edin. |
| ozan_3.wav | Dikkat. Yeni sipariş işleme hazır. |
| ozan_4.wav | Yeni sipariş bildirimi. Sipariş listesini kontrol ediniz. |

Canva Text to Speech → Türkçe → Ozan seçilerek, kullanım hakkı doğrulanmış gerçek çıktıları bu isimlerle PCM WAV biçiminde ekleyin. MP3 dosyasına yalnız uzantı değişikliği yapmayın; gerekirse kayıpsız WAV dönüştürme kullanın. Personel/Yönetici ve AlfaBildirim paketlerine bu klasör otomatik olarak dahil edilir. Uygulama hiçbir müşteri veya sipariş verisini ses servisine göndermez.
